# Drip Mode - Loja de Streetwear

Um site moderno e responsivo para uma loja de roupas streetwear, desenvolvido com HTML, CSS e JavaScript.

## 🚀 Características

- Design responsivo
- Interface moderna e intuitiva
- Carrinho de compras interativo
- Notificações em tempo real
- Seções para produtos, sobre e contato
- Integração com redes sociais

## 📋 Pré-requisitos

- Navegador web moderno (Chrome, Firefox, Safari, Edge)
- Conexão com internet (para carregar fontes e ícones)

## 🔧 Instalação

1. Clone o repositório:
```bash
git clone https://github.com/seu-usuario/drip-mode.git
```

2. Navegue até a pasta do projeto:
```bash
cd drip-mode
```

3. Abra o arquivo `teste.html` em seu navegador

## 🛠️ Construído com

* HTML5
* CSS3
* JavaScript
* [Font Awesome](https://fontawesome.com/) - Para ícones
* [Google Fonts](https://fonts.google.com/) - Para tipografia
